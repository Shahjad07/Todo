# 📝 Todo App

A simple and responsive Todo App built using JavaScript to help users manage daily tasks efficiently.

## ✨ Features

- ➕ Add New Tasks
- ✅ Mark Tasks as Completed
- ❌ Delete Tasks
- 📋 Display Task List
- ⚡ Interactive User Interface
- 💾 Dynamic Task Management using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation & Events)

## 🚀 How to Use

1. Enter a task in the input field.
2. Click the **Add** button to add the task.
3. Click on a task to mark it as completed (if implemented).
4. Click the **Delete** button to remove a task.
